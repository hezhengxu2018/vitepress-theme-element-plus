# vitepress-theme-element-plus

## 中文

一个采用 Element Plus 风格的 VitePress 文档主题，提供明暗主题、Markdown 增强和独立的移动端 iframe 预览，适合构建组件库与工具库的文档站点。

- [中文文档](https://vitepress-theme-element-plus.silver-fe.dev/zh/)

## English

A VitePress documentation theme styled after Element Plus, featuring light and dark themes, Markdown enhancements, and isolated mobile iframe previews. Suitable for documenting component libraries and developer tools.

- [English documentation](https://vitepress-theme-element-plus.silver-fe.dev/en/)
