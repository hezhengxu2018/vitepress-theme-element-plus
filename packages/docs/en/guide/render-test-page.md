## 6. Markdown syntax examples

This section showcases default VitePress Markdown rendering so you can check baseline formatting.

### Unordered and ordered lists

- List items starting with `-`, `*`, or `+` should render as unordered lists.
- Keep 4px spacing between items, and nested paragraphs should inherit line height.
  - Second-level lists should align with proper indentation. Inline code like `const foo = 'bar'` should remain monospaced.
- You can mix **bold**, _italic_, or ~~strikethrough~~ text.

1. Ordered lists should auto-number.
2. Multi-digit numbers should align with the paragraph text.
3. Check colors and states with [external links](https://vitepress.dev) or `kbd` styling.

### Blockquotes and nested content

> A top-level quote highlights a paragraph.
>
> > You can nest quotes and include lists:
> >
> > - [x] Task 1
> > - [ ] Task 2

### Emphasis and inline elements

Text like **bold**, _italic_, `inline code`, and [link text](https://element-plus.org) should follow the theme's primary colors. Inline HTML such as <sup>sup</sup> or <sub>sub</sub> should render properly. Inline MathJax (e.g. $E = mc^2$) should align to the baseline if enabled.

### Headings and outline levels <ElTag>Demo</ElTag> <ElTag type="danger">Demo</ElTag>
